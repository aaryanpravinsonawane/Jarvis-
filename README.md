# JARVIS — Futuristic AI Assistant

An advanced, sci-fi inspired AI personal assistant interface built with **React 19**, **Three.js / React Three Fiber**, **TypeScript**, and **Vite**.

---

## 🌟 Features

- **3D Holographic Orb (Three.js & React Three Fiber)**
  - Precision latitude & longitude wireframe globe
  - Multi-tiered luminous core glow with white-hot energetic center
  - Dynamic segmented orbital rings with counter-rotating telemetry arcs
  - 120+ animated orbital particle cloud
  - Restrained equatorial scanning pulse effect
  - 7 assistant state themes: `IDLE`, `CONNECTING`, `LISTENING`, `THINKING`, `SPEAKING`, `MUTED`, and `ERROR`

- **Sci-Fi HUD Architecture**
  - Dark glassmorphic aesthetic with cyan/ice-blue neon palette
  - Real-time animated audio waveform visualizer
  - Comprehensive live conversation transcript panel with auto-scroll
  - Interactive audio/control bar (Mic, Reconnect, Interrupt/Stop, State cycling)
  - Modular navigation sidebar (History, Memory, Settings, Preview modes)

- **Engineered for Speed & Modern Web**
  - React 19 + TypeScript 6 + Vite 8
  - Lightweight and responsive across desktop and mobile screens
  - Zero-warning production build

---

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript
- **3D Graphics:** Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Styling:** Vanilla CSS Custom Properties (Glassmorphism, Neon Glows)
- **Build Tool:** Vite 8

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/aaryanpravinsonawane/Jarvis-.git

# Navigate into the project directory
cd Jarvis-

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
